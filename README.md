# 📖 Gaotian Fables (高天寓言)

> 当群星隐去名字，当盛宴只剩余温，仍有人在无光之海的尽头，守望尚未熄灭的火。

这是关于游戏生态、宇宙探索与人类宿命的启示录。所有故事皆为隐喻，请自行参悟。

这里收藏的，是旧日玩家的余烬，也是远航者留给时间的密信。有人在繁华的宴席上寻找失落的滋味，有人在宇宙的沉默里追问存在的重量。诸神不作解答，深海不赐归途；翻开这些寓言的人，须亲自辨认其中的星火。

---

## 卷目 · 两扇通往深处的门

### 第一篇：[老食客与预制菜](fables/01-the-old-diners.md)

**致敬那些被资本与快餐毁掉的纯粹游戏。**

昔日的炉火渐冷，流水线上的盛宴却永不散场。老食客仍坐在原处，等待一口曾让他相信世界值得热爱的滋味。

### 第二篇：[无光海的三种渡客](fables/02-the-three-travelers.md)

**隐喻量子跃迁、物理降维与时间的琥珀。**

在光也无法归来的海上，三种渡客各自选择命运的航道。有人越过不可见的门，有人折叠自身的天地，有人将最后一次心跳封入永恒。
